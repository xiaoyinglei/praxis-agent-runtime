- [ ] **Step 3: Validate local links, directory anchors, and fenced code blocks**

Run a read-only Python check that extracts local Markdown links and top navigation
anchors from `README.md`, asserts that linked local files exist, asserts that every
`href="#..."` target is generated by a README heading, and asserts that fenced code
blocks are balanced.

```bash
uv run python - <<'PY'
from pathlib import Path
import re

path = Path("README.md")
text = path.read_text(encoding="utf-8")
assert len(re.findall(r"(?m)^```", text)) % 2 == 0
headings = {
    re.sub(r"[^\w\- ]", "", value.strip().lower()).replace(" ", "-")
    for value in re.findall(r"(?m)^#{1,6}\s+(.+)$", text)
}
for anchor in re.findall(r'href="#([^"]+)"', text):
    assert anchor in headings, anchor
for target in re.findall(r"\[[^]]+\]\(([^)]+)\)", text):
    if "://" not in target and not target.startswith(("#", "mailto:")):
        assert (path.parent / target.split("#", 1)[0]).exists(), target
print("README structure OK")
PY
```

Expected: the validator prints `README structure OK` and exits zero.
